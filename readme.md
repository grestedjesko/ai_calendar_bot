# Бот для создания задач в Google Календаре

Этот бот позволяет быстро создавать задачи и напоминания в Google Календаре с использованием естественного языка, благодаря интеграции с ИИ моделью. Просто напишите задачу, и бот автоматически создаст событие в вашем календаре.

## Функции

* Быстрое создание задач и напоминаний в Google Календаре.
* Использует ИИ для понимания запросов на естественном языке.
* Поддержка настройки через файл `.env`.

## Установка

Для запуска проекта выполните следующие шаги:

### 1. Клонируйте репозиторий

Склонируйте репозиторий на свою локальную машину:

```bash
git clone https://github.com/grestedjesko/ai_calendar_bot.git
cd ai_calendar_bot
```

### 2. Установите зависимости

Для установки необходимых зависимостей используйте pip:

```bash
pip install -r requirements.txt
```

### 3. Создайте файл `.env`

В корневой директории проекта создайте файл `.env` с необходимыми настройками:

```dotenv
BOT_TOKEN= токен вашего бота
BASE_URL= домен или IP вашего сервера
DATABASE_NAME= название базы данных
AI_KEY= ключ AI провайдера
AI_URL= ссылка AI провайдера
MODEL= модель, которую вы хотите использовать
```

Замените значения в файле на свои данные.


### 4. Настройте GOOGLE API
```
1. Перейдите на http://console.cloud.google.com/
2. Создайте свой проект
3. Нажмите Enable api and services и выберите календарь
4. Перейдите в OAuth content screen
5. Создайте OAuth клиента для WebApp
6. Добавьте в настройки Redirect Url ссылку - Ваш BASE_URL /auth/callback:
 например https://calendar.ru/auth/callback
7. Сохраните json файл и добавьте его в корень проекта под названием credentials.json
8. Не забудьте добавить нужный email в список тестовых пользователей или пройти модерацию от гугл. Иначе аунтефикация работать не будет.```
```

### 5. Настройте перенаправление
```
Настройте nginx на вашем сервере для перенаправления запросов на 8000 порт.
```

### 6. Запустите проект

Запустите сервер или бота:

```bash python -m uvicorn bot:app --port=8000 ```

Теперь бот будет работать и готов к использованию.

## Использование

Просто напишите в чате с ботом задачу или напоминание, и он автоматически создаст соответствующее событие в Google Календаре. Бот понимает запросы на естественном языке и может сам определять продолжительность задачи.

## Примечания

* Убедитесь, что у вас есть действующий ключ API для ИИ провайдера и правильно настроены все параметры в `.env`.
* Для работы с Google Календарем вам нужно будет предоставить доступ вашему боту к вашему аккаунту Google.
